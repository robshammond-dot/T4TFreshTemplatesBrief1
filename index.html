4File rules

  • Formats: JPG for banners and photos, PNG for the logo strip and buttons.
  • A little movement, if you like: the Bon Voyage and Welcome Home banners can be a subtle animated GIF, such as a plane taking off or a suitcase landing home. Please keep each one under 500KB, and make sure the first frame works on its own with the logo and label showing, as some inboxes (Outlook on desktop) only show the first frame. Supply a still JPG version of these too.
  • File names: lowercase letters, numbers and hyphens only, as in the list above, for example beach-quote.jpg.
  • Colour: sRGB.
  • Photos: from our Stockpress library, or properly licensed, with no watermarks.
  • Words in images: keep to the short label. Some inboxes hide images until the reader allows them, so anything important is typed in Fresh.

Please send back

  • All the image files above, in one folder, named as listed.
  • The editable master file, so new themes can be added later by swapping the photo and label.
Not needed from you: a coded HTML email, the message text, the footer text or links. These are all set up in Fresh.
